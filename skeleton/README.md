# Скелет веб-приложения

Голый каркас для нового сайта: архитектура фронтенда и бэкенда, переводы,
конфиги и машинная проверка архитектуры. Предметной логики, дизайна (кроме
механизма тёмной/светлой темы), авторизации, интеграций и деплоя здесь нет —
всё это добавляется под конкретный проект.

## Состав

| Файл | О чём |
|---|---|
| `01-frontend.md` | Слои FSD и правила импорта, точка входа, роутер, HTTP-клиент, ошибки, формы, тема, моки |
| `02-backend.md` | Модульный монолит, пример модуля, сборка Express, ошибки, логирование, Prisma |
| `03-i18n.md` | Переводы с проверкой полноты компилятором |
| `04-configs.md` | package.json, Vite, tsconfig, ESLint, Tailwind, PostCSS, .env.example, husky |
| `05-arch-checks.md` | Скрипты `npm run check:arch` для обеих частей |

## Стек

- **Фронтенд:** React 19, TypeScript, Vite 8, Tailwind CSS 3, react-router-dom 7,
  Zustand 5, Axios, react-hook-form + zod 4, i18next.
- **Бэкенд:** Node ≥ 20.19, Express 5, TypeScript (CommonJS), Prisma 5 + PostgreSQL,
  pino, express-validator, helmet.

## Обозначения

- `<app>` — имя проекта.
- Порты по умолчанию: фронтенд `5173`, бэкенд `5001`.
- Языки в примерах — `en`, `ru`; список задаётся в одном месте.
